# Fantasy Tripo starter set

Five new single-asset references generated with the built-in image generation tool, plus the previously approved lantern. Each PNG is a separate modeling reference. Suggested dimensions in prompts describe design intent, not guaranteed model scale. See ../PROMPTS.md for the approved lantern prompt.
